# Distribution-Based Clustering (Gaussian Mixture Models & Expectation-Maximization)

Distribution-based clustering (or latent profile analysis) assumes that the observed data points are generated by a mixture of several underlying probability distributions. The goal of the clustering process is to identify the parameters of these latent distributions and assign soft (probabilistic) or hard cluster memberships to each data point.

The most prominent distribution-based clustering model is the **Gaussian Mixture Model (GMM)**, which is optimized using the iterative **Expectation-Maximization (EM) algorithm**.

## 1. Formal Mathematical Formulation of GMMs

Let $\mathbf{x} \in \mathbb{R}^d$ be a continuous random vector. A Gaussian Mixture Model expresses the probability density of $\mathbf{x}$ as a weighted linear combination of $K$ multivariate Gaussian distributions:

$$p(\mathbf{x} \mid \mathbf{\theta}) = \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x} \mid \mathbf{\mu}_k, \Sigma_k)$$

Where:
*   $K$ is the number of mixture components (clusters).
*   $\mathcal{N}(\mathbf{x} \mid \mathbf{\mu}_k, \Sigma_k)$ is the $k$-th Gaussian density component with mean vector $\mathbf{\mu}_k \in \mathbb{R}^d$ and covariance matrix $\Sigma_k \in \mathbb{R}^{d \times d}$:
    $$\mathcal{N}(\mathbf{x} \mid \mathbf{\mu}_k, \Sigma_k) = \frac{1}{(2\pi)^{d/2} |\Sigma_k|^{1/2}} \exp\left( -\frac{1}{2} (\mathbf{x} - \mathbf{\mu}_k)^T \Sigma_k^{-1} (\mathbf{x} - \mathbf{\mu}_k) \right)$$
*   $\pi_k$ is the **mixture weight** (prior probability) of component $k$, satisfying:
    $$\sum_{k=1}^K \pi_k = 1 \quad \text{and} \quad 0 \le \pi_k \le 1 \quad \forall k$$
*   $\mathbf{\theta} = \{\pi_1, \dots, \pi_K, \mathbf{\mu}_1, \dots, \mathbf{\mu}_K, \Sigma_1, \dots, \Sigma_K\}$ represents the complete parameter set.

### The Maximum Likelihood Objective
Given an i.i.d. dataset $X = \{\mathbf{x}_1, \mathbf{x}_2, \dots, \mathbf{x}_N\}$, the log-likelihood of the parameters is:

$$\ln p(X \mid \mathbf{\theta}) = \sum_{i=1}^N \ln \left( \sum_{k=1}^K \pi_k \mathcal{N}(\mathbf{x}_i \mid \mathbf{\mu}_k, \Sigma_k) \right)$$

Because the summation over components $K$ appears *inside* the logarithm, setting the partial derivatives of the log-likelihood to zero does not yield analytical, closed-form solutions for the parameters. To solve this, we introduce latent variables and use the EM algorithm.

## 2. Latent Variable Formulation

For each observation $\mathbf{x}_i$, we introduce a binary latent vector $\mathbf{z}_i = [z_{i1}, z_{i2}, \dots, z_{iK}]^T \in \{0, 1\}^K$, which represents a "1-of-K" encoding of the cluster that generated $\mathbf{x}_i$. 
Exactly one element $z_{ik}$ is equal to $1$, and all others are $0$.

The prior distribution over $\mathbf{z}_i$ is defined by the mixture weights:
$$p(z_{ik} = 1) = \pi_k \implies p(\mathbf{z}_i) = \prod_{k=1}^K \pi_k^{z_{ik}}$$

The conditional distribution of $\mathbf{x}_i$ given $\mathbf{z}_i$ is:
$$p(\mathbf{x}_i \mid z_{ik} = 1) = \mathcal{N}(\mathbf{x}_i \mid \mathbf{\mu}_k, \Sigma_k) \implies p(\mathbf{x}_i \mid \mathbf{z}_i) = \prod_{k=1}^K \mathcal{N}(\mathbf{x}_i \mid \mathbf{\mu}_k, \Sigma_k)^{z_{ik}}$$

## 3. The Expectation-Maximization (EM) Algorithm

The EM algorithm is an iterative optimization framework used to find Maximum Likelihood Estimates when the model depends on unobserved latent variables.

### A. The E-Step (Expectation)
In the E-step, we calculate the posterior probability of the latent variables $\mathbf{z}_i$ given the current parameter estimates $\mathbf{\theta}^{(t)}$. This is referred to as the **responsibility** ($\gamma_{ik}$) that component $k$ takes for generating data point $\mathbf{x}_i$.

Using Bayes' theorem:

$$\gamma_{ik} = E[z_{ik} \mid \mathbf{x}_i, \mathbf{\theta}^{(t)}] = p(z_{ik} = 1 \mid \mathbf{x}_i, \mathbf{\theta}^{(t)}) = \frac{\pi_k^{(t)} \mathcal{N}(\mathbf{x}_i \mid \mathbf{\mu}_k^{(t)}, \Sigma_k^{(t)})}{\sum_{j=1}^K \pi_j^{(t)} \mathcal{N}(\mathbf{x}_i \mid \mathbf{\mu}_j^{(t)}, \Sigma_j^{(t)})}$$

### B. The M-Step (Maximization)
In the M-step, we update the parameters $\mathbf{\theta}$ to maximize the expected value of the complete-data log-likelihood calculated in the E-step.

Let $N_k = \sum_{i=1}^N \gamma_{ik}$ be the effective number of data points assigned to cluster $k$.

#### 1. Updating the Mean Vectors ($\mathbf{\mu}_k$)
The updated mean is a weighted average of the data points, where weights correspond to the responsibilities:

$$\mathbf{\mu}_k^{(t+1)} = \frac{1}{N_k} \sum_{i=1}^N \gamma_{ik} \mathbf{x}_i$$

#### 2. Updating the Covariance Matrices ($\Sigma_k$)
The updated covariance matrix is computed as:

$$\Sigma_k^{(t+1)} = \frac{1}{N_k} \sum_{i=1}^N \gamma_{ik} \left( \mathbf{x}_i - \mathbf{\mu}_k^{(t+1)} \right) \left( \mathbf{x}_i - \mathbf{\mu}_k^{(t+1)} \right)^T$$

#### 3. Updating the Mixture Weights ($\pi_k$)
To find the updated mixture weights $\pi_k$, we maximize the expected complete log-likelihood subject to the constraint $\sum_{k=1}^K \pi_k = 1$. Using a Lagrange multiplier $\lambda$:

$$\mathcal{L}(\mathbf{\pi}, \lambda) = \sum_{i=1}^N \sum_{k=1}^K \gamma_{ik} \ln \pi_k + \lambda \left( \sum_{k=1}^K \pi_k - 1 \right)$$

Taking the derivative with respect to $\pi_k$ and setting it to $0$:

$$\frac{\partial \mathcal{L}}{\partial \pi_k} = \sum_{i=1}^N \frac{\gamma_{ik}}{\pi_k} + \lambda = 0 \implies N_k + \lambda \pi_k = 0 \implies \pi_k = -\frac{N_k}{\lambda}$$

Summing both sides over all $K$ components to resolve $\lambda$:

$$\sum_{k=1}^K \pi_k = -\frac{1}{\lambda} \sum_{k=1}^K N_k \implies 1 = -\frac{N}{\lambda} \implies \lambda = -N$$

Substituting $\lambda = -N$ back into the expression for $\pi_k$ yields:

$$\pi_k^{(t+1)} = \frac{N_k}{N}$$

## 4. Selecting the Number of Components ($K$)

Increasing the number of components $K$ always increases (or keeps equal) the training likelihood, leading to overfitting. Model selection metrics penalize the likelihood based on the number of free parameters.

Let $P$ be the number of free parameters in the GMM:
$$P = (K - 1) + K \cdot d + K \cdot \frac{d(d+1)}{2}$$
where $(K-1)$ accounts for the mixture weights, $K \cdot d$ accounts for the mean vectors, and the final term accounts for the unique elements of the symmetric covariance matrices.

Let $L$ be the maximized likelihood value $\ln p(X \mid \mathbf{\theta}^*)$.

### A. Akaike Information Criterion (AIC)
$$\text{AIC} = 2P - 2L$$

### B. Bayesian Information Criterion (BIC)
$$\text{BIC} = P \ln N - 2L$$

**Decision Rule:** Choose the $K$ that minimizes the AIC or BIC. BIC imposes a stricter penalty on the number of parameters as the dataset size $N$ grows.

## 5. Comparison: GMM vs. K-Means

| Feature | K-Means Clustering | Gaussian Mixture Model (GMM) |
| :--- | :--- | :--- |
| **Assignment Type** | Hard assignment (each point belongs to exactly one cluster). | Soft assignment (each point has a probability distribution over all clusters). |
| **Geometry** | Assumes spherical, isotropic clusters. | Captures ellipsoidal, elongated clusters with varied orientations. |
| **Underlying Math** | Deterministic minimization of distance to centroids. | Probabilistic density estimation via Expectation-Maximization. |
| **Parameters** | Only the cluster centers (centroids). | Component means, full covariance matrices, and mixture weights. |
| **Relation** | Can be viewed as a limiting case of GMMs where component covariances $\Sigma_k = \sigma^2 I$ approach $0$. | Generalization of K-Means that accounts for covariance and variance. |

## 6. Covariance Architecture Constraints

To prevent overfitting and singular covariance matrices (where $|\Sigma_k| \to 0$ if a component collapses onto a single point), GMMs can be constrained to specific covariance architectures:

```text
    Spherical               Diagonal                  Full
   (Isotropic)         (Axis-Aligned Ellipse)    (Rotated Ellipse)
     
       O                    / \                     / \
     O   O                 |   |                   /   \
       O                    \ /                    \   /
                            
  \Sigma = \sigma^2 I     \Sigma = diag(\sigma^2)   Unconstrained \Sigma
```

1.  **Spherical (`covariance_type='spherical'`):** Each component has its own single variance parameter: $\Sigma_k = \sigma_k^2 I$.
2.  **Diagonal (`covariance_type='diag'`):** The ellipse is aligned with the coordinate axes; features are assumed conditionally independent: $\Sigma_k = \text{diag}(\sigma_{k1}^2, \dots, \sigma_{kd}^2)$.
3.  **Tied (`covariance_type='tied'`):** All $K$ components share the same general covariance matrix: $\Sigma_k = \Sigma \quad \forall k$.
4.  **Full (`covariance_type='full'`):** Each component has an unconstrained, independent covariance matrix. This provides the highest model capacity but requires estimating the most parameters.
