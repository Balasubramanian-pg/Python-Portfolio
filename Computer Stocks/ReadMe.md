# Computer Stocks Analysis

This project analyzes the financial performance, valuation, and market trends of major computer and technology companies. It uses historical data, financial indicators, and visual analytics to identify patterns and investment insights.

## Objectives

* Evaluate top computer and tech stocks (e.g., Apple, Dell, HP, Lenovo, ASUS).
* Compare key financial ratios like P/E, ROE, and EPS growth.
* Analyze market sentiment and stock performance trends.
* Visualize long-term returns and volatility patterns.

## Data Sources

* Yahoo Finance API / yfinance
* Company annual reports (10-K)
* Nasdaq / NSE historical stock data

## Tools & Libraries

* **Python**: pandas, numpy, matplotlib, seaborn, yfinance
* **Power BI / Tableau**: for dashboard visualization
* **Jupyter Notebook**: for analysis and documentation

## Project Workflow

1. **Data Collection** – Pull 5–10 years of stock data.
2. **Data Cleaning** – Handle missing values, normalize date formats.
3. **Exploratory Analysis** – Identify return patterns and volatility.
4. **Valuation Metrics** – Compute ratios and performance KPIs.
5. **Visualization** – Build trend and comparison charts.
6. **Reporting** – Summarize insights in dashboards or notebooks.

## Insights Expected

* Best and worst performers in the computer stock category.
* Correlation between R&D spending and long-term returns.
* Seasonal or macroeconomic impact on stock trends.

## How to Run

1. Clone the repo.
2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
3. Run the analysis:

   ```bash
   python scripts/analysis.py
   ```
